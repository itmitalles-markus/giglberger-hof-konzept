# Giglberger Hof – Konzeptwebsite

Kostenlose statische Testversion für den Giglberger Hof / Familie Krieger in Edling.

## Enthalten

- responsive Startseite
- visuelle Bildwelt als Grundlage für einen späteren Fototermin
- interaktiver Zaunkonfigurator
- automatische Segment-, Pfosten- und Lattenberechnung
- kopierbare Anfragezusammenfassung
- saisonaler Christbaum-Bereich

## Hinweis

Dies ist eine unverbindliche Konzeptversion. Die generierten Bilder sind keine Aufnahmen des echten Hofs. Geschäftliche Angaben, Leistungen, Bildrechte, Impressum und Datenschutz müssen vor einer produktiven Veröffentlichung mit Familie Krieger abgestimmt werden.

## Lokale Vorschau

Die Seite benötigt keinen Build-Prozess. `index.html` kann direkt geöffnet oder über einen beliebigen statischen Webserver bereitgestellt werden.
